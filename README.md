# Ключ владыки

# Краткое описание
Мини-игра-головоломка: нужно открыть кодовый замок за ограниченное время. Игрок, после смерти, оказавшись в Аду, должен подобрать код на кодовом замке портфеля Сатаны, чтобы вернуть свою душу и сбежать.

# Технологии
- Unity 2022.3.62f3
- C#
- UI Canvas
- TextMeshPro

# Платформа
- Windows
